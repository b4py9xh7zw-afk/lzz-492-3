# 商场保洁巡检排班系统

面向商场物业的保洁巡检管理系统,覆盖 **排班 → 扫码签到 → 照片留证 → 投诉追溯 → 大屏监控** 全流程。

## 功能一览

| 角色/终端 | 页面 | 功能 |
|---|---|---|
| 主管(管理端) | `/admin.html` | 按楼层/洗手间/餐饮区/扶梯口批量分配任务、查看任务状态、巡检记录(含现场照片)、投诉追溯(自动定位最近一次巡检与责任人) |
| 保洁员(手机端) | `/mobile.html` | 登录后**仅显示本人**当日巡检路线;扫点位二维码签到并**必传现场照片**;支持额外巡检签到 |
| 物业大屏 | `/screen.html` | 实时展示今日任务统计、**当前未完成点位**(超时红色闪烁)、最新完成动态、投诉预警,10秒自动刷新,列表自动滚动 |
| 顾客(公开页) | `/complaint.html` | 扫点位投诉码或手动选择点位提交脏污投诉,系统**自动追溯该点位最近一次巡检记录和负责保洁员** |
| 二维码打印 | `/qrcodes.html` | 每个点位的「员工签到码」和「顾客投诉码」,可直接打印张贴 |

## 快速开始

```bash
npm install
npm start          # 默认 http://localhost:3000
```

首次启动自动初始化 SQLite 数据库并写入演示数据(4名保洁员、13个点位、32条今日任务)。

## 核心流程

1. **排班**:主管在管理端勾选点位(可按洗手间/餐饮区/扶梯口快捷筛选)→ 选保洁员、日期、时间窗 → 批量创建(自动去重)。
2. **签到**:保洁员手机端查看本人路线 → 到点后扫描点位二维码(自动填入点位编码并匹配任务)→ 拍摄现场照片 → 提交。扫错点位、重复签到、缺照片均会被拦截并提示。
3. **超时**:超过截止时间未签到的任务自动标记「已超时」(每30秒巡检一次),大屏红色闪烁警示。
4. **投诉追溯**:顾客提交投诉时,系统自动关联该点位**最近一次巡检记录**;主管在「投诉追踪」页可看到责任人、巡检时间、现场照片及距投诉的时间间隔,并流转处理状态。

## 技术栈

- **后端**:Node.js + Express + better-sqlite3(零外部服务依赖,数据存于 `data/mall.db`)
- **上传**:multer(照片存于 `uploads/`,限制10MB、仅图片)
- **二维码**:qrcode(服务端按需生成 PNG)
- **前端**:原生 HTML/JS,无构建步骤;手机端拍照调用 `<input capture="environment">`

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` | 登录,返回 Bearer token |
| GET/POST | `/api/zones` | 点位列表 / 新增(主管) |
| GET | `/api/zones/:id/qrcode?type=checkin\|complaint` | 点位二维码 PNG |
| POST | `/api/tasks` | 批量排班(主管,自动去重) |
| GET | `/api/my/tasks` | 本人当日任务(保洁员) |
| POST | `/api/checkin` | 扫码签到(multipart: zone_code, task_id?, note, photo) |
| POST | `/api/complaints` | 顾客投诉(公开,自动追溯最近巡检) |
| GET | `/api/complaints` | 投诉列表含追溯信息(主管) |
| GET | `/api/screen` | 大屏聚合数据(公开) |

> 说明:本项目为演示实现,密码明文存储、会话保存在内存中;生产环境请替换为哈希密码与持久化会话。
